# Pax RPG 0.3.1 — прототип механики

Отдельный мод (не серия Pax CorpInc). Сейчас — механика и простой герой:

- **Юрума вместо Земли** — свой шейдер на материале домашней планеты игры (`shaders/yuruma.gdshader`,
  текстура `textures/yuruma_surface.png` из генератора `pax_rpg/dev/yuruma_planet.py`). Провинции и страны
  под ней пока земные — меняется только вид.
- **Города на глобусе** — 10 значков (`config/cities.json`, имена в `data/lang`), цвет — империя, ◆ — столица.
- **Щелчок по городу** → экран загрузки со строкой рассказчика → **локация**: платформа, блоки-ступени,
  ворота. Время мира на паузе (`pause_world` в `config/location.json`).
- **Герой — простой демон с катаной** (`models/hero_simple.glb`, ~7 тыс. треугольников, жёсткие части на
  скелете с именами костей гуманоида Godot). Анимации: Idle, Walk, WalkArmed, Draw, Sheathe. WASD — ходьба
  относительно камеры, Shift — бег, Пробел — прыжок, **F** — достать / убрать меч (пока идёт анимация, герой
  стоит), ПКМ + мышь — камера. Нет файла модели — герой снова овал. Модель собирается скриптом
  `pax_rpg/dev/blender/simple_hero/build_simple_hero.py` (там же проверка и экспорт).
- **Ворота**: подойти и нажать **E** → загрузка → обратно на карту мира.
- **Сценарий «Юрума»** — пресет мира `presets/Юрума/` (meta.json, земли империй, обложка): старт —
  **1 Персика 1047 года Эры Расколотого Неба**, свой календарь (месяцы Нефрита … Снегов, эра «Э. Р. Н.»),
  пять империй-фракций с вождями, целями и лором, Северный договор, война Орды Гхарн с Империумом Саэрит,
  правила для ИИ-рассказчика (азиатское фэнтези, D&D 2024, без пороха, народ они). Источник —
  `pax_rpg/scenario/yuruma.json`, сборка — `python pax_rpg/dev/yuruma_scenario.py`.
- **Своя карта провинций** — `data/regions2.*`: 420 провинций Юрумы с азиатскими названиями вместо земных
  (тот же формат, что «карта из картинки» игры; сверено с её импортёром — карта совпадает побайтно). Пока
  мод включён, земные пресеты на этой карте не сходятся с границами — играть с ним пресет «Юрума».

Конфликтует с Pax CorpInc3D (оба меняют шейдер планеты) — включать без него. Нужен «Разрешить код» в лаунчере.

## Устройство

| Файл | Что делает |
|---|---|
| `main.gd` | только регистрирует части |
| `src/planet/planet.gd` | шейдер на планете, значки городов, щелчок по ним |
| `src/travel/travel.gd` | переходы карта ↔ город, пауза мира |
| `src/travel/loading.gd` | экран загрузки |
| `src/location/location.gd` | мир локации (SubViewport со своей физикой), герой, камера, ворота |
| `src/location/gfx.gd` | качество картинки: SDFGI, SSIL, TAA, тени огней, туман, экспозиция, DOF, облака и блики, ветер для шейдеров (`config/location.json → gfx`) |
| `src/location/motion_blur.gd` | размытие в движении (CompositorEffect по векторам движения) |
| `src/location/grass.gd` | сплошная трава с ветром и топтанием (`shaders/grass.gdshader`) |
| `src/location/landscape.gd` | степь (`steppe.gdshader`), горные хребты (`mountain.gdshader`), юрты |

Концепт графики — `pax_rpg/docs/Графика_концепт.md`.

## Проверка

Без игры: `GODOT=… sh pax_rpg/dev/godot_test/run.sh` — сценарий щелчок → локация → ходьба → ворота → карта
на заглушках игры. В игре: `godot --headless --path <игра> -- --check-mods pax_rpg`.

## Сценарий: как поставить

Игра 0.24 берёт пресеты только из папки пользователя (`%APPDATA%\Pax Universe\presets\`), мод туда писать не
может. Поставить: из папки игры `& .\pax_corporations_dev\install_yuruma_preset.ps1` (скрипт —
`pax_rpg/dev/install_yuruma_preset.ps1`) или скопировать `presets/Юрума` туда руками. Затем в меню «Пресеты» —
«Юрума» → играть. Если новая версия игры сама видит пресеты в модах — копировать не нужно.
