# Как устроено хранилище

Отдельное хранилище только для Pax RPG (другие моды — в своём). Исходник — папка `obsidian/Pax RPG Vault` в
репозитории; на ПК — `C:\MODS\Pax RPG`, обновляется скриптом `pax_rpg/dev/obsidian_sync.ps1`.

## Правила (для автора и для Claude)

1. **Одна заметка — одна сущность** (место, механика, персонаж, файл кода). Имя заметки = имя сущности.
2. **Свойства в начале заметки** — по ним фильтр и поиск:
   - `тип:` хаб · диздок · лор · место · город · механика · персонаж · код · пайплайн · задача · журнал
   - `статус:` идея · в работе · в игре · отложено
   - `ветка:` номер ветки (01…09), если заметка лежит не в своей папке
   - `связано:` список [[ссылок]] на заметки других веток — это и есть связи между ветками в графе
3. **Хаб ветки** — главная заметка папки; все заметки ветки ссылаются на хаб, хаб — на все заметки.
4. **Ссылка «вверх» и «вбок»:** каждая заметка ссылается на свой хаб и хотя бы на одну заметку другой ветки
   (механика → код, место → лор, персонаж → механики).
5. **Теги** — только сквозные признаки: `#ии`, `#бой`, `#сеть`, `#город/гхарн`, `#идея`, `#баг`.
6. **Картинки** лежат рядом с заметкой, к которой относятся.

## Как искать

- Граф: цвет = ветка (раскраска в `.obsidian/graph.json`); толстые узлы — хабы.
- Поиск по свойству: `[тип:механика]`, `[статус:идея]`, тег: `#ии`.
- Что связано с заметкой — панель «Обратные ссылки».

## Шаблоны

`_Шаблоны/` — заготовки: место, механика, персонаж, задача (вставка: команда «Шаблоны: вставить»).
