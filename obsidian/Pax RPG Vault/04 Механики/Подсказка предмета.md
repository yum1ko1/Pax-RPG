# Подсказка предмета

**Что делает игрок:** наводит курсор (или фокус геймпада) на вещь в инвентаре.
**Что отвечает игра:** через 0,11 с рядом со слотом плавно всплывает подсказка в стиле инвентаря: имя цветом
редкости, тип, редкость, уровень, основные статы, дополнительные статы (усиленные — со свечением), требуемый уровень и цена.
**Числа:** тайминги ниже. Статы — [[Статы снаряжения]].
**Код:** нет. Живой прототип — artifact «Подсказка предмета Pax RPG» (https://claude.ai/artifact/1UrkfFi2GGRjUNgDTdK7wS);
картинки макета — `pax_rpg/reference/inventory/`.

## Состав (сверху вниз)

1. **Шапка:** иконка вещи в рамке цвета редкости · имя (цвет редкости, лёгкое свечение) · тип · РЕДКОСТЬ · «Ур. N».
   Фон шапки — мягкое пятно цвета редкости из левого верхнего угла. **В правом верхнем углу — кольцо фиксации.**
2. **Орнамент:** золотая линия с ромбом посередине.
3. **Статы древом:**
   - подпись «ОСНОВНЫЕ»; основные статы крупнее, у каждого слева ромб-узел (заливка цветом редкости);
   - от узлов вниз идёт золотой «ствол»; подпись «ДОПОЛНИТЕЛЬНЫЕ»; дополнительные статы сдвинуты вправо,
     к каждому от ствола идёт горизонтальная ветка (последняя ветка — уголок └);
   - основной-как-доп. — приглушённее; **усиленный** — строка цвета редкости (фиолет / золото / красный), свечение
     текста, полоса фона, значок ✦ справа, медленное «дыхание» 3,6 с.
4. **Блок сета** (только у вещей сета): орнамент · имя сета бирюзовым и «N / 8» (N — сколько надетых вещей из этого
   сета, при любой редкости) · 8 ромбиков по слотам (залит — в слоте вещь этого сета, обведён — текущий слот) · бонусы «(2) Название: что даёт» — действующие бирюзовым, недействующие приглушены ·
   строка из лора курсивом · «Действует при любой редкости вещей сета». У закреплённой — мини-подсказка бонуса:
   подробнее, «Нужно вещей сета: K · надето: N», «Бонус действует» / «Не хватает: M». В шапке вещи — метка «СЕТ».
5. **Подвал:** «Требуется ур. N» · «Цена N зол.». Строки-подсказки об управлении в подсказке не пишем.

Ширина 316 px (при 1080p), рамка — двойная золотая линия по тёмному лаку, ромбики на верхней кромке.

## Фиксация и мини-подсказки

- **Фиксация:** пока курсор на слоте, кольцо в углу заполняется по часовой стрелке за **1,2 с**; заполнилось —
  подсказка **закреплена**: кольцо превращается в золотую печать-ромб, рамка ярче, по подсказке проходит блик.
- Ушёл со слота раньше — подсказка прячется как обычно, кольцо сбрасывается.
- **Закреплённая** не пропадает, пока игрок не кликнет в любое место экрана **или по самой подсказке**; Esc — тоже
  закрывает. Пока закреплена, другие слоты подсказку не открывают.
- **Мини-подсказка стата:** у закреплённой подсказки наведение на строку стата открывает рядом (слева, если есть
  место) маленькую подсказку: иконка и имя стата, что он даёт, «На этом предмете: +N», пометка — «✦ Усилено
  свечением ×K», «Основной стат в роли дополнительного · 45 % силы» или «Основной стат предмета». Появление —
  160 мс прозрачность + сдвиг 6 px.
- **Геймпад / касание:** касание слота закрепляет сразу; касание стата — мини-подсказка; касание вне — закрыть.

Тексты мини-подсказок:

| Стат | Что даёт |
|---|---|
| Атака | Прибавляется к урону каждого удара, приёма и добивания. |
| Броня | Снижает урон, который вы получаете от ударов. Чем больше брони, тем меньше выгода от каждого нового очка. |
| ОЗ | Очки здоровья: увеличивают максимум здоровья героя. |
| ХА | Увеличивает запас концентрации: дольше держите блок и серию ударов, позже ломается стойка. |
| Шанс крита | Вероятность, что удар станет критическим. |
| Крит. урон | На сколько процентов критический удар сильнее обычного. |
| СПР физ. урону | Сопротивление физическому урону: снижает урон от оружия, когтей и снарядов. |
| СПР стих. урону | Сопротивление стихиям: снижает урон от огня, льда, молний и маны разлома. |
| Скорость атаки | Ускоряет удары и серии ударов. |

## Выбор вещи в слоте

- **Клик по слоту** — рядом со слотом (там же, где подсказка) открывается список вещей **только этого типа** из сумки:
  шапка «Шлем · N в сумке», дальше группы по сетам (имя сета бирюзовым), в строке — иконка в рамке цвета редкости,
  имя цветом редкости, редкость; надетая вещь обведена бирюзовым и помечена «надето».
- Клик по строке — вещь надевается, список закрывается, в слоте сразу новая иконка, всплывает её подсказка, счётчики
  сетов пересчитываются. Клик вне списка, повторный клик по слоту или Esc — закрыть.
- Пока список открыт, подсказки слотов не всплывают. Появление списка — как у подсказки (180 / 240 мс).
- В тестовой версии в сумке все вещи обоих сетов во всех редкостях (12 на слот).

## Анимация

| Что | Как |
|---|---|
| задержка показа | 110 мс после наведения; при переходе со слота на слот — 40 мс, без повторного «вылета» |
| появление | прозрачность 0 → 1 за 200 мс; сдвиг вниз 8 px → 0 и масштаб 0,965 → 1 за 280 мс, кривая cubic-bezier(.16, 1, .3, 1); размытие 3 px → 0 за 220 мс |
| центр масштаба | сторона, обращённая к слоту (подсказка «растёт» из слота) |
| блик | один проход светлой полосы по подсказке за 900 мс, с задержкой 120 мс; при закреплении — ещё раз, 700 мс |
| строки | каждая въезжает слева на 6 px и проявляется за 260 мс, по очереди через 28 мс |
| кольцо фиксации | заполняется линейно 1,2 с; печать «выпрыгивает» за 220 мс (лёгкий перелёт масштаба) |
| усиленные строки | после появления — мягкое свечение, цикл 3,6 с |
| скрытие | 90 мс задержки, затем 120 мс прозрачность и сдвиг обратно |
| reduced motion | только прозрачность |

**Место:** слева от слота (колонка экипировки справа); не влезает — справа; по высоте — вровень с верхом слота,
прижимается к краю окна, если не влезает.

**Godot:** `PanelContainer` + `NinePatchRect` (рамка), `VBoxContainer` со строками; появление — `Tween` на `modulate:a`,
`position`, `scale` (pivot — сторона слота), строки — свои `Tween` с задержкой `i * 0.028`; кольцо — `TextureProgressBar`
(fill mode clockwise) по таймеру 1,2 с; ветки древа — `Line2D` / `draw_line` в `_draw()` (тонкие линии чётче
картинок); подсказка и мини-подсказка — отдельный `CanvasLayer` поверх инвентаря; закреплённая ловит клик через
`_input` (любой клик — закрыть, кроме наведения на строки).
