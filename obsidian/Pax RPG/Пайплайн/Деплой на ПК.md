# Деплой на ПК

В папке игры git с remote `pax-rpg`: `git fetch pax-rpg main`, файлы — `git show pax-rpg/main:<путь> > <путь>`
(двоичное — `git archive --format=zip`). Файлы с ПК обратно — `send_png.ps1` → ветка `pax-rpg-renders`
репозитория Pax-CorpInc. Это дерево Obsidian — `pax_rpg/dev/obsidian_sync.ps1`.
