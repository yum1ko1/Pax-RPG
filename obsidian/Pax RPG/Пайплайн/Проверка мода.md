# Проверка мода

`tools/ci/` в репозитории. На каждый push — GitHub Actions «Проверка мода»; на ПК —
`pax_corporations_dev\pax_rpg_ci\tools\ci\run_checks.ps1 -ModDir mods\pax_rpg -Shot`.

1. Статика: JSON, CodeGuard, переводы, файлы из конфигов.
2. Компиляция всех .gd в Godot с заглушками API (из `api-reference.md` игры) — ошибки с файлом и строкой.
3. Прогон [[Арена|арены]] ботом — ошибки выполнения, скриншот.
