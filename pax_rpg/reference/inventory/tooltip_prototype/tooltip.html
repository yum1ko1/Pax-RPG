Подсказка предмета

Наведите курсор на вещь в колонке экипировки — всплывёт подсказка; если держать курсор, кольцо в углу заполнится и подсказка закрепится, тогда на статы и бонусы сета можно наводить. Клик по слоту открывает список вещей этого типа: в тестовой версии там все вещи обоих сетов во всех редкостях. Бонусы сета считаются по надетым вещам при любой их редкости.

Наведите на вещь — подсказка, клик — выбрать другую

Редкость

Значения статов умножаются на множитель редкости. Усиленный стат дополнительно умножается на коэффициент свечения. Числа примерные, для настройки баланса.

Статы

Диапазоны указаны для обычного предмета 1-го уровня. Уровень предмета: числовые статы ×(1 + 0,1·(ур − 1)), проценты ×(1 + 0,03·(ур − 1)). Основной стат в роли дополнительного даёт 45% своего диапазона.
