Подсказка предмета

Наведите курсор на вещь в колонке экипировки — всплывёт подсказка; если держать курсор на вещи, кольцо в углу заполнится и подсказка закрепится (увели раньше — не закрепится), тогда на статы и бонусы сета можно наводить. Клик по слоту открывает список вещей этого типа: в тестовой версии там все вещи обоих сетов во всех редкостях. Бонусы сета считаются по надетым вещам при любой их редкости. Оружие: верхнее окно — основное, среднее — второе; клик по окну — выбрать оружие, медальон между окнами — поменять их местами. Одно оружие не может стоять сразу в обоих слотах, герой в центре держит основное.

Редкость

Значения статов умножаются на множитель редкости. Усиленный стат дополнительно умножается на коэффициент свечения. Числа примерные, для настройки баланса.

Статы

Диапазоны указаны для обычного предмета 1-го уровня. Уровень предмета: числовые статы ×(1 + 0,08·(ур − 1)), проценты ×(1 + 0,02·(ур − 1)). Надеть можно с уровня героя «уровень предмета − 5 + ступень редкости» (обычное 0 … мифическое 5). Основной стат в роли дополнительного даёт 45% своего диапазона.
