## Выкат (по шагам)

1. Проверка в контейнере: `NO_SMOKE=1 tools/ci/run_checks.sh` (статика и компиляция), потом без `NO_SMOKE` (10 с арены).
2. Поднять версию в `mods/pax_rpg/mod.json`: `version` и оба `name` («Pax RPG X.Y.ZY»).
3. Коммит с трейлерами, `git push origin claude/project-thread-r12710`.
4. На ПК (мост 21212, `shell`): `git -C C:\Users\mbkli\pax_rpg_sync pull --ff-only pax-rpg claude/project-thread-r12710`.
5. Перед перезаписью сверить файлы игры с прошлым коммитом:
   `git -C <wt> hash-object --path=mods/pax_rpg/<файл> <путь в игре>` против `git -C <wt> rev-parse <старый>:mods/pax_rpg/<файл>`.
   Не совпало — кто-то правил на ПК: слить, а не затирать.
6. Скопировать старые файлы в `claude_backup\<имя>`, затем новые из рабочей копии в `mods\pax_rpg`.
7. Тот же день — версия в main (PR сливает автор или Claude по её слову).

## Проверка в игре (мост 21212)

`game_start` → клик «Играть» (x 0.07, y 0.745) → ждать ~90 с → `ESC` (заставка) → «Continue» (x 0.58, y 0.367) →
консоль: `rpg_arena`, `rpg_city gharn`, `rpg_perf bench` (~40 с), `rpg_perf gpu` (~4 мин). Лог запуска:
`tools\pax_mcp_bridge\runs\game_*.txt` (кириллицу читать через `-Encoding UTF8` и base64). Каждый запуск занимает
главный монитор автора — запускать только когда нужно.

## CI

`.github/workflows/checks.yml`: на каждый PR — статика, компиляция, 10 с арены (~7 мин). Город Гхарн — только кнопкой
Run workflow с галкой «city» (~30 мин на программном OpenGL). Новый пуш отменяет прошлую проверку ветки.

## Известное

- Вылет 0xc0000374 при закрытии игры — не наш (падает и без Pax RPG), И-23.
- Замер FPS у ворот Гхарна (настройки автора, RTX 5070 Ti): день ~108, ночь ~80. Больше всего стоят постройки
  города (MultiMesh −2.6 мс, модели −1.8) и тени солнца (−2.2).
