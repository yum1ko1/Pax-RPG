# Монтаж ролика «Битва при Расколе»

Пайплайн монтажа вступительного ролика (заметка в Obsidian: «Ролик — Битва при Расколе»).
Рабочая папка на ПК: `C:\Users\mbkli\Videos\Pax_Intro` (`media/` — исходные клипы c01…c13).

1. `python run_all.py` — LUT по актам → звук (стемы + мастер −14 LUFS) → слои (кинорамка 2.39, субтитры RU/EN,
   титры) → VFX-плёнки ProRes (наезды, тряска на ударах, вспышки, ореол, анаморфный блик, хроматика, зерно,
   переходы) → эталонный рендер → `PaxIntro_Build.lua` в папку скриптов Resolve.
2. DaVinci Resolve: Workspace > Scripts > Utility > PaxIntro_Build — собирает проект (V1 плёнки с LUT,
   V2 рамка, V3 титры RU, V4 титры EN, A1 мастер + стемы, маркеры) и рендерит MP4.

`edl.py` — монтажный лист и все удары/переходы: правка таймингов — там.
