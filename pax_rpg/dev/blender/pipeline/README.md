# Конвейер персонажа Meshy → игра (живой Blender через blender_live.ps1)

Черновые шаги, отработанные на первом герое (9 окт.). Числа (высота подставки, ось меча, суставы) — под ту
модель; для новой их надо снять заново (замеры — в истории сессии: срезы по высоте и профиль вдоль оси меча).

1. `01_clean_scale_decimate.py` — убрать подставку, закрыть подошвы, рост 1,8 м, ступни на нуле, игровая версия ~70k.
2. `02_split_sword.py` — отделить меч по оси (клинок / цуба / рукоять / навершие), сердцевина рукояти в кулаке.
3. `03_rig_and_weights.py` — скелет 28 костей (имена гуманоидного профиля Godot), кость Weapon, точки
   WeaponBack / WeaponHand, IK левой руки, автоматические веса.
4. `04_animations.py` — Idle, Walk (цикл 32 кадра), Draw / Sheathe (меч из-за спины в руку и обратно).

После каждого шага — проверочный рендер (`pax_rpg_blender_util.shot`) и только потом следующий.
