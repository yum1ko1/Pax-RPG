# Проверка мода вне игры

Ловит ошибки до запуска игры: на каждый push в GitHub (вкладка **Actions** → «Проверка мода») и вручную.

| Шаг | Что ловит |
|---|---|
| `static_checks.py` | битый JSON; запреты песочницы CodeGuard (из `docs/modding/en/04-code.md` игры); ключ перевода есть в ru, но нет в en; `tr_key("…")` без перевода; ссылки кода и `config/*.json` на несуществующие файлы мода |
| компиляция | все `.gd` мода собираются в Godot; ошибка — с файлом и строкой (`at: GDScript::reload (res://mods/pax_rpg/…:строка)`) |
| прогон арены | мод грузится как в игре (`main.gd` → пункт меню «Тест: арена»), бот 10 с ходит, бьёт комбо, захватывает, блокирует, уворачивается, пьёт эликсир; любая ошибка выполнения — провал. В CI — скриншот `arena.png` |

API игры заменяют заглушки: `gen_stubs.py` строит их из `pax_api/api-reference.md` — копии
`docs/modding/en/api-reference.md` из папки игры (те же классы, методы и типы). Вышла новая версия игры —
скопировать справочник заново. Чтение файлов мода и переводы в заглушках настоящие — `stub_overrides/`.

## Запуск

- **GitHub:** само, на каждый push. Итог — в отчёте запуска, логи и скриншот — артефакт `pax-rpg-check`.
- **Linux:** `tools/ci/run_checks.sh` (Godot скачается в `.cache/godot`; свой — `GODOT=<путь>`).
- **Windows (ПК):** `tools/ci/run_checks.ps1 -ModDir <папка игры>\mods\pax_rpg` — без окна;
  `-Shot` — окно на 10 с и скриншот `out\arena.png` (без окна мышь не захватывается, удары ЛКМ бот не делает).

Итог — строка `== ИТОГ`, код выхода 1 при ошибках, логи — `tools/ci/out/`.

Ограничение: Godot тут официальный (4.5), а в игре своя сборка 4.7 — редкие отличия движка проверка не увидит.
